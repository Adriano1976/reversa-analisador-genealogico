analisador-genealogico

Genetic Genealogy Path Analyzer — encontra, mapeia e visualiza a conexão genealógica entre uma pessoa-raiz e seus DNA matches.

Arquitetura

Aplicação Web Flask Monolítica

Servidor Python/Flask com renderização server-side (Jinja2 + Bootstrap 5). Análise sob demanda: a cada requisição o GEDCOM é re-parseado e o grafo reconstruído. Sem banco persistente — estado em memória.
