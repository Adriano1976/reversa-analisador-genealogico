Upload e Parsing de GEDCOM

Confiança 🟢 CONFIRMADOPrioridade: MustSpec: upload-gedcom

Recebe um arquivo GEDCOM (.ged), salva-o em uploads/, faz o parsing da árvore genealógica e constrói o grafo de famílias em memória para a sessão.

Responsabilidades

Salvar arquivoPersistir o .ged enviado na pasta uploads/
Parsear registrosINDI (pessoas) e FAM (famílias) via ged4py
Construir grafoNetworkX bidirecional de pessoas ↔ famílias
Listar nomesOrdem alfabética para seleção posterior

Regras de Negócio

Upload exigeCampo de arquivo gedcom obrigatório
Sem arquivoErro "Nenhum arquivo GEDCOM enviado."
Arquivo sem nomeErro "Nenhum arquivo selecionado."
Exceção no parsingMensagem de erro com detalhe, sem crash
Pessoa s/ nomeListada como "Sem Nome"
OrdenaçãoNomes em ordem alfabética

Critérios de Aceitação

Dado um GEDCOM válido (ex.: "familia.ged")
Quando o usuário envia o arquivo no campo "gedcom"
Então o arquivo é salvo em uploads/, o grafo é construído e a lista de nomes é exibida

Dado que nenhum arquivo foi enviado
Quando o usuário submete o formulário sem o campo "gedcom"
Então a mensagem "Nenhum arquivo GEDCOM enviado." é exibida

Dado um arquivo GEDCOM malformado
Quando o sistema tenta fazer o parsing
Então uma mensagem de erro com a exceção é exibida sem quebrar a aplicação
