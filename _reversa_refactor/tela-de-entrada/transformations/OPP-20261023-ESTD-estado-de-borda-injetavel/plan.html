2. Costura proposta

Injeção por construtor no composition root, com um único ponto de leitura nos handlers. O app de módulo continua usando os mesmos objetos como padrão. 

_SEM_INJECAO = object()
CHAVE_DA_BORDA = "analisador"


def _estado_de_borda() -> dict:
    return current_app.extensions[CHAVE_DA_BORDA]


def create_app(config=None, *, armazenamento=None, carregador=None,
               registro=_SEM_INJECAO, dependencias=None) -> Flask:
    aplicacao = Flask(__name__)
    ...
    aplicacao.extensions[CHAVE_DA_BORDA] = {
        "armazenamento": _ARMAZENAMENTO if armazenamento is None else armazenamento,
        "carregador": _CARREGADOR if carregador is None else carregador,
        "registro": _REGISTRO if registro is _SEM_INJECAO else registro,
        "dependencias": _DEPENDENCIAS if dependencias is None else dependencias,
    }
    ...

A sentinela existe só para o registro, porque None é um valor válido: significa persistência desligada. Para os outros três, None não é um valor válido, e o padrão do módulo entra.

4. O que fica de fora

Mover o estado para outro módulo. Não é necessário para injetar, e mudaria a topologia de pacotes, que é território de modularize.

  • Trocar as portas de src/ports/ ou o Protocol da fronteira.
  • Tirar o dono das assinaturas: é costura declarada do ADR-26.
  • Mudar a regra dos três estados da persistência (ADR-27).
  • Mexer em src/web/rotas_assets.py: ele lê só current_app.config.
  • Trocar Dependencias de classe concreta para Protocol: é outra oportunidade.
