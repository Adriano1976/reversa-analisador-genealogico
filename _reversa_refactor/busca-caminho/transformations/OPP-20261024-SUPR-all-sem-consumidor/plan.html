Os quatro nomes continuam existindo no módulo e continuam importáveis por nome: from core.documentary_relationship import ROMANO funciona exatamente como hoje. 4. Por que não apagar o import de `ROMANO`

Apagar seria a leitura agressiva, e foi descartada. __all__ é anúncio; a importação é comportamento. Remover o import quebraria from core.documentary_relationship import ROMANO para qualquer consumidor fora do repositório, e não há ganho nenhum em quebrar: o custo real do import sem uso é uma linha, e o comentário explica por que ela fica.

O mesmo raciocínio vale para death_date e get_children, que também ficam: os dois têm consumidor real, ainda que congelado em _reversa_bugs/, caminho que a config não libera. A OPP-20261023-DOCF já registrou o preço de tratar consumidor congelado como ausente.

5. Fronteira de comportamento

Nenhuma. __all__ não governa importação explícita, e não há um único import * no repositório (verificado). Os catorze nomes anunciados continuam acessíveis, e os quatro retirados também.
