## Antes observado

`src/app.py`, dentro de `index()`, repetia o mesmo par de guardas antes de ramificar para os dois
fluxos pós-upload (análise de DNA e busca de caminho):

```python
gedcom_filename = request.form.get("gedcom_filename")
if not gedcom_filename:
    return render_template("index.html", message="Erro: Arquivo GEDCOM não encontrado.", success=False)
gedcom_path = _resolver_caminho_armazenado(gedcom_filename)
if gedcom_path is None:
    return render_template("index.html", message=f"Erro: Arquivo '{gedcom_filename}' não existe mais.", success=False)
all_names = load_gedcom_and_build_graph(gedcom_path)
```

O bloco aparecia antes do ramo `dna_analysis` e antes do ramo `path_search`, com as mesmas duas
mensagens. Eram 9 linhas duplicadas em uma função que a decisão D2 mantém como camada de rota
fina, sem nenhuma das 118 regras de negócio.

## Transformação aplicada

Extraída uma função de módulo, `_gedcom_do_formulario()`, que devolve `(caminho, mensagem)`.
Cada chamador trata a mensagem antes de parsear, preservando a ordem exata dos efeitos
colaterais do código anterior:

```python
def _gedcom_do_formulario():
    """Caminho da árvore pedida pelo formulário, ou `(None, mensagem)`.

    Devolve o CAMINHO, e não o nome recebido: quem lê depois usa o que foi
    resolvido, sem remontar caminho. As duas mensagens são as que a rota
    publicava antes da extracao, ao pé da letra.
    """
    nome_recebido = request.form.get("gedcom_filename")
    if not nome_recebido:
        return None, "Erro: Arquivo GEDCOM não encontrado."
    caminho = _resolver_caminho_armazenado(nome_recebido)
    if caminho is None:
        return None, f"Erro: Arquivo '{nome_recebido}' não existe mais."
    return caminho, None
```

E cada ramo passou a chamar:

```python
gedcom_path, erro = _gedcom_do_formulario()
if erro is not None:
    return render_template("index.html", message=erro, success=False)
all_names = load_gedcom_and_build_graph(gedcom_path)
```

Decisão de forma registrada: a função **não** chama `load_gedcom_and_build_graph`. Devolver a
árvore já parseada seria mais curto, mas mudaria o momento do parse em relação a validações
posteriores de cada ramo, e o parse substitui o estado global do processo. Preservar o instante
exato da chamada é o que mantém a transformação comportamentalmente neutra.
